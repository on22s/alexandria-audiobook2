# Voice presentation and continuity

The Voices tab offers an optional, user-confirmed vocal presentation hint, such as "lower, resonant female voice". It is separate from narrative gender/age and per-line emotion. Model-based voice suggestions receive it as vocal matching guidance; deterministic fallback remains based on the existing persona/traits. Suggestions still require user review and application. The field is not a new TTS control: saving it alone does not alter the assigned voice, waveform or source annotations.

The "Choose Main voice throughout" shortcut is available for any detected state timeline, including age-only changes. It changes the visible selections only. Review the base voice and selections, then Apply. Preserve explicit switches for genuine transformations or time skips if desired. Existing book ownership guards, confirmation when clearing a timeline and changed-only audio invalidation remain in use. No GPU rendering begins merely from saving a timeline.

Possible reveal detection is advisory. Automatic presentation inference remains in the experimental probe; appearance, personality, dialogue style and another speaker's description are not verified vocal evidence. No automatic identity rewrites or retrospective speaker-label changes are introduced.
