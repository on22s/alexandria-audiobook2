# Hugging Face releases

Publish only artifacts with verified redistribution rights.

Public releases should include:

- the exact tested file hash;
- base model and license;
- training data sources and rights;
- prompt variant and serving command;
- complete evaluation results and limitations.

Negative evaluation reports can be published without uploading restricted
adapter weights or source text. Failed or setup-defect adapters should be
labelled clearly and should not be promoted as quality models.
