# 声の種類

[日本語ホーム](Home-JA.md) · [English](Voice-Types.md)

Voices では各話者に声のカードを設定します。

## モデルと声の種類

| モデル | ID | 用途 |
|---|---|---|
| CustomVoice | `Qwen3-TTS-12Hz-1.7B` | 演技指示に対応する 9 種の声 |
| Base | `Qwen3-TTS-12Hz-1.7B-Base` | Clone、LoRA |
| VoiceDesign | `Qwen3-TTS-12Hz-1.7B-VoiceDesign` | 説明文から声を生成 |

必要な時点でモデルをロードし、キャッシュします。現在の種類に必要なモデルを GPU に載せます。

| UI の種類 | 適した用途 | バッチ |
|---|---|---|
| Custom Voice | ナレーション、主要人物 | 対応 |
| Built-in Voice | 同梱の学習済みの声 | 対応 |
| Voice Clone | 特定の参照音声の声 | 話者別に対応 |
| LoRA Voice | 長く登場し、演技指示も必要な人物 | アダプター別に対応 |
| Voice Design | 1–3 行ほどの端役 | 1 行ずつ |
| Together | 複数人が同時に話す行 | メンバーの声を使用 |

外部 Gradio TTS は CustomVoice / Clone に対応します。Voice Design / LoRA は **local** モードが必要です。

## Custom Voice / Built-in Voice

Custom Voice は Aiden、Dylan、Eric、Ono_anna、Ryan、Serena、Sohee、Uncle_fu、Vivian から選びます。Ryan と Aiden は英語のネイティブ話者です。**Character Style** と各行の指示を使えます。

Built-in Voice は `builtin_lora/` の既製アダプターを使います。初回に Hugging Face からダウンロードし、LoRA と同じように動作します。

## Voice Clone

5–15 秒ほどのノイズのない参照録音を使います。**Designed Voice** で Designer に保存した声を選ぶか、**Custom Path** に WAV のパスを入れ、**Reference Text** に正確な文字起こしを指定します。約 7 秒より短い参照は不安定になりやすく、インポート時に正規化と計測を行います。アップロード時は文字起こし、出典、権利の根拠を記録します。

**Clone は行ごとの演技指示を使用しません。** 声は参照音声から作られます。同じ話者の行をまとめ、参照プロンプトをキャッシュします。

## LoRA Voice

Base に学習済みアダプターを載せ、学習時の参照音声と演技指示を使います。[学習ガイド](Training-Guide-JA.md)を参照してください。Clone は手早く始められます。LoRA は学習が必要ですが、多くの行で声を保ちながら感情・読み方を指定できます。アダプター単位でバッチ処理します。

## Voice Design

**Description** に年齢、声域、声質などを書き、行の `instruct` と組み合わせます。**行ごとに新しく声を生成するため、同一人物の声を固定する方式ではありません。** 3–4 行を超える役には、デザインした声を保存し、Clone の参照にする方法があります。

Description は恒常的な声質、`instruct` は感情や読み方に使います。「穏やかな声」と「激怒して叫ぶ」など矛盾を避けてください。Voice Design はバッチ対応の種類が終わってから 1 行ずつ生成します。

## Together

メンバーがそれぞれの声で同じ行を読み、音声を混ぜます。最長のクリップに合わせるため、厳密なユニゾンというより合唱のようになります。

## 声の固定記述とタイムライン

**Character Style** は声の特徴を保つ identity anchor（固定記述）です。例として `Heavy Scottish accent` のような特徴を毎行に加えます。Custom では固定記述が先、行の指示が後。LoRA / Built-in では行の指示が先、固定記述が後です。

スタイルのタイムラインでは「時間が飛んだ後は年を取った声」などを、指定の行から適用できます。同じ話者のまま声の特徴を変えます。Editor の **Check Voices** は参照との類似度でずれを調べ、該当行をフラグ表示します。声の種類や説明文による一貫性の比較は[英語ページ](Voice-Types.md#how-consistent-is-each-type)を参照してください。

## Generate Personas

1. LLM が話者の行を読み、声の説明とサンプル文を作成します。
2. VoiceDesign で参照音声を生成します。
3. 各話者に **Voice Clone** として割り当てます。

既定の対象は **Only characters without a voice yet**。全人物も選択できます。現在の声を先にライブラリーへ保存するオプションがあります。**Advanced** のバッチサイズは既定で 40 です。

ペルソナの声は Clone なので、行ごとの演技指示を使いません。表現を重視する役は後で Custom / LoRA に切り替えます。参照は `designed_voices/` に保存されます。**Suggest LoRA Voices** は手持ちの学習済みの声から候補を提案します。

## 人物の状態別ペルソナ

全体のペルソナ生成を Advanced で行うと、人物の確定した年齢・性別の状態ごとに、対応する会話と近くの地の文を使ったペルソナとプレビューを作成します。後で同じ状態が再登場しても、別の番号のカードになります。

**Show cards** で全人物、状態カードあり、状態カードなしを切り替えます。状態カードには独立した声の種類、参照音声・文字起こし、説明、スタイル、seed、承認、候補プールがあります。欠けている・古くなったペルソナは声を編集する前に生成してください。古くなるのはその状態の区間の会話や地の文が変更されたときで、別区間の編集ではありません。基本の声と手動バージョンは人物の展開可能な基本声セクションに残ります。

Advanced の **Only characters without a voice yet** は欠落・古い状態も生成します。1 枚の状態カードからの再生成はその状態だけを対象にします。成功した状態は保存し、失敗した状態の以前の設定を保持して、状態別にエラーを示します。

### 状態の声を適用する

生成・編集だけでは、生成済み音声へ声の変更は適用されません。基本声セクションの **Voice changes** で候補を確認し、**Apply** を押します。その後の音声生成がタイムライン境界で声を切り替えます。

結合済みの行の途中に変更点がある、編集後の会話との対応がずれた、台本が古い場合は、行を再構築・確認する必要があります。該当する状態を警告付きでスキップし、他の状態は適用します。状態の声はタイムライン専用で、人物の本全体の声として選択しません。

タイムラインの適用・編集・解除で、実効的な声が変わる行だけが Pending になります。Editor の **Render Pending** で再生成します。古い音声はディスクに残りますが、Pending の行は再生成が成功するまで書き出し対象から外れます。

大きな年齢差なしの既知の性別変化は **Possible identity reveal** として確認を求めます。名前は台本どおりです。同じ声を通して使うなら基本声を設定し、**Main voice throughout** を選んで **Apply** します。選択だけでは保存されません。

既知の年齢ラベル、再生可能な参照音声、文字起こしがある保存済み Designer 声も、LoRA とともに **Voice changes** に表示され、Clone 参照として使われます。年齢・性別で候補を案内し、明示的な子供の年齢区分の一致を優先します。他の人物で使う声は再利用と表示し、欠落・破損した参照を除外します。基本声に使う場合は **Voice Clone** で保存済み Designer 参照を選びます。

**Remove saved state persona** は未適用の状態を消し、音声ファイルと他の声を保持します。再生で使っている場合は先にタイムラインの該当点を解除します。配役をライブラリーへ保存すると手動バージョンは残りますが、状態バージョンやタイムラインを別の本へ持ち込みません。

**Recover persona** はその状態を指定した手動復旧を開きます。復旧パネルで人物名を直接入れる場合は、基本ペルソナか番号付き状態を明示します。復旧・Resume は基本声と他の状態を保持します。コピーするプロンプトには対象の状態の会話と文脈だけを使ってください。

## 別名

カードの **Alias of** で別の話者の声を使えます。名前の表記揺れ、肩書きなどをまとめます。A → B → C なら A は C の声を使用し、循環は警告を記録して停止します。設定は `voice_config.json` の `alias_of` に保存されます。
