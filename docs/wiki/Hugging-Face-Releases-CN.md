# Hugging Face 发布

[中文主页](Home-CN.md) · [English](Hugging-Face-Releases.md)

公开的适配器位于 [Om22s/alexandria-qwen3-attribution](https://huggingface.co/Om22s/alexandria-qwen3-attribution)。完整的发布检查清单见 [HF_MODEL_GUIDE.md](../../HF_MODEL_GUIDE.md)。

## 可以发布什么

只有再分发权利已经核实过的文件。

## 每次公开发布必须包含

- 被测试的那个确切文件的哈希；
- 基座模型及其许可证；
- 训练数据来源及其权利；
- 训练时使用的提示词，以及服务启动命令；
- 完整的评估结果，包括局限性。

## 适配器命名

每个适配器名称都以它训练时用的提示词结尾，因为适配器只在该提示词下有效：

| 标签 | 提示词 |
|---|---|
| `attrv1` | 2026-09-14 之前的归属提示词 |
| `attrv2` | 2026-09-14 起的归属提示词 |
| `michel2v1` | `MICHEL2_SYSTEM`，1,825 字符（#619/#623 之前） |
| `michel2v2` | `MICHEL2_SYSTEM`，2,071 字符（#619/#623 之后） |

提示词文本本身发布在该合集的 `prompts/` 文件夹中。

## 负面结果

- 负面评估可以在不上传受限适配器权重或源文本的情况下发布。
- 失败的适配器，或存在设置缺陷的适配器，必须清楚标注，绝不能被当作质量模型推广。
- 已发布的结果后来被更正时，模型卡会说明这一点以及改了什么——例如 2026-09-28 的重评分，作为 collection v1.6.1 发布。
