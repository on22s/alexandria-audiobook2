# 編集と書き出し

[日本語ホーム](Home-JA.md) · [English](Editor-&-Export.md)

Editor は行単位の「chunk（分割された行）」を編集・生成・試聴する画面、Result は完成した音声を書き出す画面です。

## 行の編集

各行には **Status**（Pending / Done / Error）、**Speaker**、**Text**、**Instruct** があります。フィールドを編集すると自動保存されます。行の **generate** ボタンでその行だけ再生成するか、**Render Pending** で未生成の行をまとめて生成します。行の追加・削除もできます。

## 発音

### 1 つの発音を直す

**Pronunciation** を開き、共有ルールを読み込み、**Preview counts and line voices** を実行します。行を選んで **Load line rules** を押し、元の綴りと読み上げる置き換えを入力します。次に **Find original spelling** で対象を探し、意図した一致を下書きとして追加します。一致の対象は、キューや記号を整理したあとに読み上げ用として準備された文章です。台本そのものは変わりません。

限られた英単語リストの走査には、行ルールを読み込んだあと **Discover English homographs** を選びます。既存の完全一致の単語境界を使って lead/read/wind を見つけるもので、網羅的な言語解析、意味の推論、散文の言語判定ではありません。解決された TTS 言語が English である必要があります。出現箇所の横に読み上げる置き換えを入力し、意味と例を選ぶと、利用者が選んだ意味のメモを持つ未承認の下書きが作られます。すでに下書き済み・承認済みの範囲で繰り返しクリックしても下書きは増えません。確認と承認は明示的に行い、検出は音声生成、ルールの保存、文章やテイクの変更を行いません。結果が切り詰められた場合は後ろの一致が省略されます。

下書きを確認し、**Approved** を選び、**Save line rules** の前に **Preview line** を実行します。下書きと却下したルールは読み上げに影響しません。承認した出現ルールは、その出現箇所について共有ルールより優先されます。挿入した置き換えが二度置換されることはありません。任意の制限で、作者の話者、割り当て済みの声またはアンサンブル、言語、エンジンモードを指定できます。音素ヒントは、プレーンテキストのエンジン向けに明示的な読み上げの代替が必要で、ない場合はプレビューがバイパスされたと報告します。

行ルールの保存は、実行中の処理の完了または中止を待ちます。実効的な読み上げが変わった行だけが Pending になり、以前の音声ファイルは保持されます。メモと無効な下書きは既存の音声を保持します。言語やエンジンモードの変更も、影響する条件付きの行を Pending にします。プレビューは TTS モデルをロードしません。上記の試聴は、選んだ行の声で使い捨ての音声を生成します。試聴と生成した行を聴いて読みを判断してください。

ルールは現在の Editor の行の同一性に属します。行を並べ替えてもルールは保持されますが、文章を編集すると新しい一致の確認が必要です。保存した台本を読み込み・再構築すると新しい行が作られ、出現ルールは引き継がれません。重なる承認済みの出現箇所と古い一致は拒否されます。生成したテイクは、適用・バイパスした判断を音声リビジョンとともに記録するため、後からレビューのメモで以前の演技を書き換えることはできません。

## 音声生成

- **Render Pending**：音声が必要な行を生成。
- **Regenerate All**：全行を再生成。
- `local` はバッチ処理、`external` は 1 行ずつ並列リクエスト。[バッチ生成](Batch-Generation-JA.md)を参照。
- GPU ロックに従い、同じ GPU の LLM が台本を作成している間は開始しません。LLM が別の GPU / マシンの場合は設定で明示します。
- **Cancel**：処理を中止し、完成した行は保持。

## 確認と試聴

**Check Voices** は参照音声との ECAPA 類似度でずれを検出し、**flagged only** で該当行だけ表示します。**Text integrity** は元の文章との差を語ごとに表示します。生成したファイルは音声として検証され、破損した行にフラグが付きます。これらの検査に加えて、実際に聴いて確認してください。

行の再生ボタンで個別に、**Play Sequence** で順番に再生します。Setup の **Speaker Change Pause** は既定 500 ms、**Same Speaker Pause** は既定 250 ms です。

## 保存したテイクのスナップショット

生成した行を開いて **Saved take snapshots** を選びます。言葉、声、seed を変える前や再生成の前に **Save this take** を押すと、選択中の音声と、記録された文章、話者、演技、seed カウンター、利用可能な根拠の不変コピーを保存します。**This line's snapshots** でコピーを試聴し、**All project snapshots** で以前の行や本の世代のコピーを探せます。再生は保存したバイト列を検証し、選択中の行の音声は変更しません。

**Protect** は削除を防ぎます。**Delete with undo** はスナップショットを再生から隠しますがバイト列は保持し、**Undo deletion** で戻します。**Remove permanently…** は別の確認付き操作で、保存領域を解放し、元に戻せません。現在のスナップショット、参照中のスナップショット、保護されたスナップショットのファイルは削除できません。自動の整理は行われません。

プロジェクトのアーカイブは、本と行の同一性ごとに 16 レコード、合計 4,096 レコードと 1 GiB のペイロードまでです。各コピーは 64 MiB、モノラル・ステレオ、10 分までに制限されます。メタデータは 1 レコード 128 KiB、1 マニフェスト 16 MiB までで、加えて 16 MiB の保留中のメタデータ書き込みが 1 つあります。削除したコピーと中断したコピーは、明示的に削除するまで数えます。失敗・中断したコピーが選択中の音声を置き換えることはなく、計上された不完全なレコードは整理のために表示され続けます。不明・破損したアーカイブのメタデータは、黙って修復・削除せず、確認用に保持します。

**Automatic take history** は既定で無効です。Editor でそのセクションを開き、**Refresh setting** を押してから **Turn on** にすると、再生成の前に以前選択していた演技を保持します。アーカイブの制限は変わりません。以前のテイクを安全に保持できない場合、置き換えの前に再生成が拒否されます。**Turn off** は新しい自動スナップショットを止めますが、既存のスナップショットは残り、保留中の以前のテイクは置き換えが成功するまで保護されたままです。

対応ホストでは、現在の本と行の復元根拠がそろった準備済みのスナップショットに **Check & restore** が表示されます。ボタンは適格性の検査を開始するもので、復元できることを保証しません。復元は保存した音声と、その元の生成依存関係を現在の行と照合し、置き換えられるテイクを保持し、新しい音声を生成せずに保存した演技を選択します。置き換えられるテイクを安全に保持できない場合は復元を拒否します。互換性のないスナップショットに合わせて作者の台本を変更することはありません。検証済みの復元は、対応する Linux ホストの組み込みローカル CustomVoice、VoiceClone、LoRA で利用できます。保存した演技には、合成ウィンドウと復旧を有効にして生成したネイティブの公開根拠が必要です。現在の Clone 参照のバイト列と LoRA アダプターの世代が、記録された実行依存関係と一致している必要があります。その根拠がない古いスナップショットは試聴には使えます。

復元根拠が一致しない、削除されていない旧形式の録音やスナップショットも試聴には使えます。文章、声、モデル設定、その他の記録済みの依存関係を変更すると、スナップショットが復元に適さなくなることがあります。保存した台本を読み込むと行の同一性が新しくなり、古いスナップショットは **All project snapshots** に残りますが、位置や文章で新しい行に割り当てられることはありません。

## 結合

**Merge All** は有効な音声を順番に結合し、Result に表示します。各行の先頭・末尾の不要な無音を除いてから、設定した間を入れます。未完成や Pending の行がある場合は、書き出す前に文章の欠落がないか確認してください。

## 書き出し

### MP3

Result から全体の 128 kbps MP3 をダウンロードします。ファイルは `cloned_audiobook.mp3` です。

### M4B

**Export M4B** で章マーカー付きのファイルを作ります。**Title**、**Author**、**Narrator**、**Year**、**Description**、**Cover Image** を設定し、**Per-chunk chapters** も選べます。

### 書き出しの整合性検査

Result は、以前の納品物を置き換える前に、完成した MP3、M4B、章音声を検査します。この検査は、エンコードされた音声を独立したソースフレームの計画と比較し、破損したサンプルや非有限のサンプルがないかデコードし、M4B の章マーカーと作者が設定した本のメタデータを確認します。失敗・中止した書き出しは以前の納品物を保持します。

**Export integrity checks** で、次の書き出しの無音しきい値と許容する最大の想定外の間隔を設定します。長い無音は既定で警告になり、**Reject exports with unexpected long silence** を有効にすると拒否します。作者が設定した行間の間は除外されます。この検査は発話内容や発音を保証しません。

**Show checks for this book** は、完了した検査を拒否された試行と分けて表示し、フレーム数や無音・章の時間範囲を含みます。結果はこのアプリのセッション中、書き出しの種類ごとに最大 32 の納品物と 16 の拒否された試行まで保持されます。ファイルのメタデータが変わるとレシートは表示されません。開いても音声の再ハッシュやデコードは行いません。SHA-256 の値は、完了した検査時点のバイト列を表します。書き出しの公開自体は、完全なファイルのバイト列とソースの同一性を検査します。

Audacity は ZIP のメンバー、WAV ヘッダー、各トラックの正確なフレーム数、LOF / ラベル、アーカイブの CRC を検査します。非アクティブな話者の間は意図的なもので、ナレーションの欠落とは扱いません。

### 章別ファイル

**Export chapters** で章ごとの MP3 / WAV を作ります。`{chapter_number} - {chapter_name}` のようなテンプレート、番号のゼロ埋め、本・シリーズ名、巻、章一覧、行別ファイル、変更した章だけの書き出し、ファイル名プレビューに対応します。ファイルと ZIP は `chapter_exports/` に保存されます。

### 行別ファイル

`voicelines/` に読み順の番号と話者名で保存されます。たとえば `voiceline_0001_narrator.mp3`、`voiceline_0002_elena.mp3` のような名前です。

### Audacity

**Export to Audacity** は話者ごとの WAV トラックを含む `audacity_export.zip` を作ります。

```text
audacity_export.zip
├── project.lof
├── labels.txt
├── narrator.wav
├── elena.wav
├── marcus.wav
└── ...
```

1. ZIP をダウンロードして展開します。
2. Audacity で `project.lof` を開くと、全トラックを読み込めます。
3. **File > Import > Labels** で `labels.txt` を読み込みます。

各トラックは同じ長さになるよう無音で埋められ、同時再生すると結合 MP3 と同じ配置になります。人物ごとの音量・効果、行間のタイミング調整に使えます。

## 小さい・壊れた MP3

428 バイト程度の MP3 は ffmpeg が見つからない、または MP3 をエンコードできない場合に生じます。インストーラーは環境に ffmpeg を導入するため、`app/env` の外で起動していないか確認し、Pinokio または正しい環境で再生成してください。[トラブルシューティング](Troubleshooting-JA.md)に詳細があります。
