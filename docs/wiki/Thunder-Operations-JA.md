# Thunder 運用

[日本語ホーム](Home-JA.md) · [English](Thunder-Operations.md)

リモートの Thunder GPU マシンでジョブを実行するときのルールです。

## 変更する前に

- 各マシンは**同時に 1 つの GPU ジョブ**だけを実行します。
- まずプロセス一覧とジョブのログを確認します。

確認に使えるコマンド：

```bash
date '+%I:%M %p %Z'
ps -eo pid,ppid,etime,cmd
tail -f /home/ubuntu/<job>/eval.log
```

## 実行中のジョブを変更する

- **実行中のシェルスクリプトを編集しないでください。** Bash はスクリプトを読みながら実行するため、編集すると実行中のジョブが誤った位置に飛ぶことがあります。新しい名前で新しい版を書き、それを起動してください。
- **ジョブは PID で停止**し、実行が無効と判明した場合にだけ停止します。
- ジョブのパターンに **`pkill -f` を使わないでください**。それを実行しているシェル自身に一致して kill することがあります。

## 進捗の報告

まだ実行中のジョブでは、測定したウィンドウごとの時間を報告し、残作業の見積もりとは分けて示します。
