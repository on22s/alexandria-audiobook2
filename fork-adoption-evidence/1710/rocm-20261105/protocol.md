# ROCm-only #1710 qualification protocol

Frozen before new GPU runs, 2026-11-05. CUDA is explicitly untested and #1710 stays open. Public Qwen base and Watson adapter only; synthetic English text; no private audio or inference inputs leave this machine.

- Numeric phase: actual native ROCm, sequential fp32 and bf16 base loads. Capture six real Qwen prefill inputs. Round canonical embeddings to bf16 then lift to fp32 so every arm receives identical numeric embeddings, not independently rebuilt prompts. Compare fp32 adapter-minus-base logit deltas with bf16 merged-minus-base and unmerged-minus-base deltas. Record L2 retention, cosine, relative L2 error, finite checks and input hashes. Qualification requires lower median relative error for unmerged and no line more than 20% worse than merged. No waveform-equivalence claim.
- Audio phase: six short sentences, seeds 1710 and 2710; bf16 no-LoRA (same prompt, adapters disabled), bf16 merged control, bf16 unmerged production loader. One warm-up each, then twelve timed renders per arm. Keep every result, including failures. Actual engine generation, no altered sampling parameters; 256-token bound. Record wall time, duration, seconds-per-audio-second, peak memory, output SHA256, native Qwen speaker embeddings. This is batch-one native Windows qualification only.
- Coverage: independent local CPU Whisper small.en, ordered edit-distance word error and final two expected words. Qualification target: <=5% aggregate WER and both ending words present in the final transcript suffix for all new unmerged clips; decoder failures remain unknown, not passing. Scorer controls must reject missing, reordered and truncated text.
- Identity instrument: fixed native Qwen speaker encoder, normalized embeddings, leave-one-text-out nearest-centroid classification of unmerged vs no-LoRA. Exclude both seeds of each held-out sentence from training. Require >=75% balanced accuracy and positive average signed margin; disclose every prediction. Identical-vector and zero-vector controls. This tests measurable voice-embedding separation, not perceptual identity or guaranteed superiority. If it does not separate at 1x, mark identity unqualified; do not substitute a convenient post-hoc threshold or treat ECAPA as proven.
- GPU ownership: each bounded process acquires authoritative native gpu_guard lock; no contention override. Require >=10GiB VRAM (12GiB for fp32 numeric arm) and >=12GiB free system memory. One process/arm, release in finally, checkpoint each arm. Failed process/timeout stops the chain; no silent retries.
- All review clearances predate new source repairs and must be refreshed. Recovery certification stays unsupported and explicitly disclosed for unmerged mode; no fabricated merged certificate. Full tests/release gates remain separate.
